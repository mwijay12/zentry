# Zentry — Metagame Landing Page

An awwwards-style scroll experience: clip-path section transitions, animated typography and a dark, cinematic layout. Built to practise advanced CSS masking and timeline choreography.

**Live:** [zentry-livid-five.vercel.app](https://zentry-livid-five.vercel.app)

## Stack

React · Vite · Tailwind CSS · GSAP · react-icons

## What's in it

- Hero with animated title treatment
- Clip-path "video frame" transitions between sections
- Scroll-scrubbed GSAP timelines
- Bento-style feature grid
- Responsive layout down to small phones

## Running locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Structure

```
src/          sections, components and animation hooks
public/       video and image assets
tailwind.config.js
```
